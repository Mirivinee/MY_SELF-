# Portfolio + AI Digital Twin

Personal portfolio website with an interactive AI digital twin. See [CLAUDE.md](./CLAUDE.md) for
the full project spec, phases, and folder structure.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · GSAP + ScrollTrigger
